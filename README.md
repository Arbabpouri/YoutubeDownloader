# 📥 Download Videos and Music from YouTube

This project is a simple and practical script for downloading videos and music from YouTube. With this script, you can easily download videos in various qualities or extract the audio from a video and save it as an audio file.

## 🚀 Features

- **Video Download**: Download videos in multiple quality options.
- **Audio Download**: Extract audio from videos and save it as an MP3 file.
- **User-Friendly Interface**: Easy to use through the command line.

## 📋 Prerequisites

To use this script, you need to have Python installed along with the pytube and colorama libraries. You can install them using the following commands:


```
pip install colorama
pip install pytube
```
